# CarBase

Aplicação Flutter para gerir veículos, manutenções, inspeções, impostos,
despesas e o histórico da garagem.

## Executar

```bash
flutter pub get
flutter run
```

## Estrutura

- `lib/app`: configuração e identidade visual da aplicação;
- `lib/core`: modelos, constantes e utilitários partilhados;
- `lib/data`: fontes de dados (atualmente dados de demonstração);
- `lib/features`: funcionalidades organizadas por área de negócio;
- `lib/shared`: componentes reutilizáveis.
